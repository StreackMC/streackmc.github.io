# summary.js 的「名单」—— 只总结命中这里所列模式的页面
#
# · 一行一个模式；以 # 开头的行是注释，空行忽略
# · 模式匹配的是**网站路径**（如 /doc/policy/donate），不是 dist 里的文件路径
# · 开头的 / 可以省略
# · 通配符：`*` 任意多个字符（不含 /）、`**` 跨层级、`?` 单个字符
# · 只写目录名（如 doc/policy）时，该目录**及其下所有页面**都会被纳入
# · 以 / 结尾（如 doc/policy/）等价于 doc/policy/**
# · 以 **!** 开头表示**强制排除**：命中的页面一律不总结，
#   无论它是否落在纳入范围内、也不论书写顺序（排除始终优先）
# · 只写排除项（没有纳入项）时，基准是「全部可读页面」，即「除了这些，其余都总结」
# · 本文件为空（或全部被注释）时不做过滤，照旧处理全部可读页面
# · 命令行 `node summary.js --only "doc/**,!doc/event/**"` 可临时覆盖本名单
#
# ── 示例（取消注释即可生效）────────────────────────────────────
#
# 整个文档区
# doc/**
#
# 只要「政策与方针」目录及其下的页面
# doc/policy
#
# 只要某个单页
# /doc/policy/privacy
#
# 通配符：webtool 下任意一层
# /webtool/*
#
# 多目录
# doc/**, about/**
#
# 纳入 + 排除：文档区里跳过活动页
# doc/**
# !doc/event/**
#
# 只要排除项：除活动页与调查页外，其余全部总结
# !doc/event/**
# !doc/survey/**
