- **frame 里的组合根**：`entry.js` / `init.js` 是唯一允许静态引用 component 的 frame 模块

- **可选组件按需加载**：`counting` 由 FrameworkLayout 默认追加，页面无需声明；
  `videoBg` / `loopCards` 由页面 `features="…"` 声明

  但暴露点统一收敛到 `frame/api.js`

### 环境坑（踩过）
- **zsh 不对未加引号的变量做分词** → `for f in $FILES` 把整个多行串当一个元素 → 改用 `xargs -I{}`
- `git add a b c` 中只要有一个路径不存在就会整体失败（其余路径也未暂存）→ 分开 add 并核对 status
- Node 22 的 `globalThis.navigator` 是只读 getter → 需 `Object.defineProperty` 覆盖
- 沙箱「批量删除守卫」：build 清理 dist（>50 文件）会被拦，旧产物需手动 `rm`
- `public/` 是直接复制，增量构建会留下已删源文件的旧产物 → 查产物前先 build、再按需清理
