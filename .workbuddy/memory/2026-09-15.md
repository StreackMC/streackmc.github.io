## 新增 Markdown 内容管线

为项目接入 Markdown 渲染能力，核心原则：**内容目录与网站路径 1:1 镜像**。

### 映射规则
- 内容根目录 `src/content/`，其下目录结构原样映射为 URL：`src/content/<路径>.md` → `/<路径>`
- 目录形式的 `index.md` 去掉末尾 index 段：`src/content/docs/aaa/index.md` → `/docs/aaa`
- 根级 `index.md` 映射为 `/`（路由中已过滤，避免与首页冲突）

### 新增文件
- `src/content.config.ts` — Content Collection `content`，glob loader（base `./src/content`，pattern `**/*.md`），schema: title/description/keywords/theme
- `src/pages/[...slug].astro` — 根级 catch-all，`getStaticPaths` 遍历集合，slug = `entry.id.replace(/(^|\/)index$/, '')`；正文含顶级 `#` 则不重复渲染页头
- `src/layouts/DocLayout.astro` — 继承 FrameworkLayout，正文放入 `.content.doc-content > .doc-article > .doc-body`
- `public/assets/code/doc.css` — prose 样式（标题/段落/列表/引用/代码/表格/图片…），以 `.doc-content .doc-body …` 高特异性覆盖 framework.css 的 `.content *` 默认重置
- 示例内容：`src/content/docs/index.md`(/docs)、`docs/guide/index.md`(/docs/guide)、`docs/guide/markdown-syntax.md`

### 关键点
- doc.css 必须晚于 framework.css 加载（通过 `<link slot="head">`，顺序在 FrameworkLayout CSS 之后）以在特异性相同时胜出
- `.content > *` 为绝对定位，DocLayout 用 `.contents .content.doc-content > .doc-article { position: static; display:block }` 覆盖
- 构建：15 页（原 12 + 新 3 个文档页），sitemap 自动收录 `/docs/**`
