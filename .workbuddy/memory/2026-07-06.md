## Sitemap 配置优化
- **问题**：customPages 手动维护遗漏了 h5event 活动页、webtool/status_next 系列页面
- **修复**：customPages 改为自动扫描 `public/` 下所有 HTML，排除 `assets/app/includes/`（框架片段）和 `assets/archived-file/`（归档页）
- **模式**：移除单文件合并集成，恢复 @astrojs/sitemap 默认的 `sitemap-index.xml` + `sitemap-0.xml` 分片输出（用户有其它架构项目也用分片模式，保持一致）
- **外部 sitemap**：robots.txt 预留了外部 sitemap 添加位置，用多个 `Sitemap:` 指令引用（搜索引擎标准支持跨项目 sitemap）
- **Bug 修复**：`findHtmlFiles` 递归时 `relative(dir, fullPath)` 的 base 跟着子目录变，导致路径前缀丢失（`/webtool/credits.html` → `/credits.html`），进而排除规则失效。修复为 base 固定在最外层
- 收录 URL 从 11 个增至 14 个（8 Astro + 6 静态）
