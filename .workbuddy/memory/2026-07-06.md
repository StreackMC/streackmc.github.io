- **修复**：customPages 改为自动扫描 `public/` 下所有 HTML，排除 `assets/app/includes/`（框架片段）和 `assets/archived-file/`（归档页）

## GitHub Pages 部署失败修复
- **根因**：上次失败的 workflow run 残留了 `github-pages` artifact，新 run 又上传同名 artifact，`deploy-pages@v4` 找到两个后报错 "Multiple artifacts named github-pages were unexpectedly found"
- **修复**：
  - workflow 添加 `actions/github-script@v7` 清理步骤，部署前自动删除仓库中残留的旧 `github-pages` artifact
  - `concurrency.cancel-in-progress` 改为 `true`，新部署取消旧部署
  - 添加 `actions: write` 权限允许删除 artifact
  - 添加 `public/CNAME`（streack.top 自定义域必需）
  - `configure-pages` 添加 `enablement: true` 自动设置 Pages Source 为 GitHub Actions
  - 添加 `ASTRO_TELEMETRY_DISABLED` 环境变量
- **注意**：用户在 commit 860ac4a 中删除了 3 个 minecraft 页面（有意行为，"修复错误引入"），当前构建为 6 个 Astro 页面
