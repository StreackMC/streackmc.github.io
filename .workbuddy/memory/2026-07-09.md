## 修复非首页 Footer 计时器不显示 (commit pending)

### 根因
- `pmd.js` 使用 `const conf = { ... }` 声明，`const` 在浏览器全局作用域中**不会**挂载到 `window` 对象（与 `var` 不同）
- `framework.js`（ES Module）的 `initCounting()` 通过 `window?.conf?.info?.time` 读取配置 → 始终为 `undefined` → 直接 return，计时器从未启动
- 首页计时器能工作是因为 `home.js` 直接硬编码 `refreshCountup(2024, 12, 25)`，不依赖 `window.conf`

### 修复
1. **`FrameworkLayout.astro`** — inline script 中 `window.streack` 初始化后追加 `window.streack.conf = typeof conf !== 'undefined' ? conf : null;`，将 pmd.js 的全局 `const conf` 桥接到 `window.streack.conf`（不污染 window 顶层）
2. **`framework.js initCounting()`** — 读取路径从 `window?.conf?.info?.time` 改为 `window?.streack?.conf?.info?.time`
3. **`pmd.js`** — 不改动（撤销之前 `window.conf = conf` 的方案）
4. **`home.js`** — 移除重复计时器逻辑，统一由 `framework.js initCounting()` 处理所有页面
