## 多项 UI/CSS 修复 (commit 56841c6)

### SPA src="false" 修复
- astro-spa v1.3.9 的 Spa.astro 第 127 行 bug：`external && path.substring(6)` 在 external=false 时输出 `src="false"`
- 改为 `external ? path.substring(6) : undefined`，Astro 正确处理 undefined 不输出属性

### 全局 footer 计时器
- framework.js 新增 `refreshCountup()` + `initCounting()` 函数
- `initCounting()` 从 pmd.js 的 `conf.info.time` 读取配置，支持精确到秒
- 在 `initFramework()` 末尾自动调用 → 所有 FrameworkLayout 页面均获得计时器
- 首页 home.js 的计时器仍通过 `requestInitFunc` 注册，会覆盖 framework 版本（无冲突）

### pmd.js time 数组扩充
- `[true, 2024, 12, 25]` → `[true, 2024, 12, 25, 0, 0, 0]`（末尾追加，不破坏已有元素）

### CSS --lh 行高变量
- framework.css `:root` 新增 `--lh: unset`
- 全局规则 `p { line-height: var(--lh, 1.5lh) }`

### DownloadLayout 优化
- 说明区合并为一段：`download-hero` 含版本号 + 一句话描述 + 时间
- 默认字体 `--fs:1rem;--fl:1.2rem;--lh:1.5lh`
- 移除 `download-meta:hover` 淡化恢复效果（始终淡化）
- SHA256 等宽字体：`"SF Mono", "Menlo", "Monaco", "Consolas", monospace`
