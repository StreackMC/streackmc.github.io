## Selector 分层选择器模版
新建了 Apple 隐私页风格的分层选择器模版，位于 `public/webtool/` 下：
- `selector.html` — 页面入口，Sober UI shell (s-page light + s-appbar + s-scroll-view)
- `code/css/selector.css` — 样式：pill 选项按钮、面包屑、结果卡片、入场动画、light/dark 双主题
- `code/javascript/selector.js` — 逻辑 + `SELECTOR_CONFIG` 配置树

### 交互特性
- 正文流依次展示：标题 → 描述 → 选择区
- 选项卡逐层展示，点击进入下一层（基于 `children` 数组）
- 新出现的选项卡自动滚动至视口中央（`scrollIntoView({ block: 'center' })`）
- 某层仅一个选项时自动选中并继续（700ms 延迟）
- 面包屑导航可点击回退到任意层级
- 最终结果以卡片形式展示（`result.title` + `result.content` HTML）
- "重新选择"按钮重置整个选择器

### 数据结构
每个选项节点：`{ label, hint?, children? | result? }`
- `children` → 有子选项，继续下钻
- `result: { title, content }` → 最终结果
- 两者互斥

### 与项目集成
- 遵循 webtool 模式（与 status.html / credits.html 一致）
- 引用项目公共资源（pmd.js、Sober UI CDN、字体）
- 可通过修改 `SELECTOR_CONFIG` 快速适配法律/隐私/帮助等页面

- **slot 冲突处理**：`<div style="display: contents">` 包裹层隔离 HTML slot 属性与 Astro 插槽指令

## Selector 模版 — 嵌入组件版本
原有 SelectorLayout 是整页布局，无法插入其他页面。新增嵌入组件版本。

### 新增文件
- `src/components/Selector.astro` — 自包含嵌入组件，接受 `config` prop，内含 CSS/JS 引用

### JS 重构（selector.js）
- 从单实例改为多实例：扫描页面上所有 `[data-selector]` 元素
- 每个实例从自身内部 `[data-selector-config]` 读取配置，独立初始化
- 向后兼容：如果找不到 `[data-selector-config]`，回退到旧的 `#selector-config`
- 防重复初始化：`data-selector-init="true"` 标记

### CSS 变化（selector.css）
- 新增 `.selector-wrap.selector-embed` 样式（无 `.content` 覆盖，无 `min-height: 100vh`）
- 整页模式样式保持不变

### SelectorLayout 变化
- `.selector-wrap` 添加 `data-selector` 属性
- 配置脚本从外部 `#selector-config` 移入 `.selector-wrap` 内部 `[data-selector-config]`

### 用法
- 整页模式：`<SelectorLayout config={config} />`（独占页面）
- 嵌入模式：`<Selector config={config} />`（插入任意页面，支持多实例）
