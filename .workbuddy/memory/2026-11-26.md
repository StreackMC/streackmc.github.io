# 2026-11-26

## Release 构建压缩 public/ 静态资源
- 新增 `tools/minify-public.mjs`：扫描 `public/` 的 `.js`/`.css`，对 `dist/` 同路径文件用 esbuild `minify` + `legalComments: 'none'` 压缩并去注释；`--check` 可与源码比对校验产物。
- `package.json` 增加 `build:release`（`npm run build && node tools/minify-public.mjs`）与 esbuild devDependency；`npm run build` / `npm run dev` 保持不压缩供调试。CI 改为 `npm run build:release`。
- 验证：release 构建压缩 50 个文件，325466 → 177600 字节（节省 45.4%）；全部 dist JS 通过 `node --check`；`--check` 返回 0。调试构建的 pmd.js / entry.js 与 public 原文哈希一致。
- 未处理 public 下的 HTML/图片/JSON（避免破坏页面语义）；如需压缩 HTML 需另选保守方案。

## Release 构建插入 HTML 版权注释
- 新增 `tools/insert-copyright.mjs`：遍历 `dist/**/*.html`，在 `<!DOCTYPE>` 前插入 `<!-- Copyright © 2026, kdxiaoyi & Streack. 保留所有权利。 -->`；幂等，`--check` 可校验。
- `build:release` 追加该步骤；脚本随后扩展到 HTML/CSS/JS 全部覆盖（含 Astro 生成的 CSS）。验证：84 个 HTML、16 个 CSS、35 个 JS 全部带版权头，`--check` 返回 0。
- 版权文案统一抽到 `tools/license-header.mjs`（js/css/html 三种形式），JS/CSS 压缩后只保留这一行版权头（此前“不保留注释”的唯一例外）；HTML 头部也使用该文案。
