## loop-cards 停顿模式：跨首尾步进修复（提交 `c1ad358`）

用户反馈两点：「切换上一个没有新的卡片补充」「切换下一个到末尾后会回到开头」。

**同源根因**（都是上一轮重构留下的）：轨道只克隆了尾部一圈，且 `wrap()` 在 `apply()`
**之前**就把位移加了 `span`。前者让首卡往左滑时无内容可补（滑出空白）；后者让 CSS 过渡
把「倒退一整圈」演成动画 —— 整条轨道倒着滑回开头。连续模式之所以看不出第二个问题，
是因为它每帧只动约 1.2px 且不带过渡，等价位移本就不可见。

**改法**：
- 轨道改三段式：前导克隆 + 原始 + 尾部克隆（3N 个子元素）
- 位移锚定中间一圈：`canonicalOffset(m) = -(span + m*step)`，恒定落在 `[-2span+step, -span]`
- 步进只走 ±step（越界那步落在克隆上 → 方向始终正确），过渡结束后 `normalize()`
  以「关过渡 + 强制重排」瞬间归位（那一刻画面完全相同，肉眼不可见）
- 「等价位移」抽成纯函数 `nearestOffset(current, target, span)`，步进与 `jumpTo` 共用
- 连续模式的整圈回绕改用同一区间（`wrapContinuous`）
- 顺带修正 reverted-* 的索引方向（索引跟着画面走，此前进度点与画面相反）

**验证**：DOM stub 自检 39 项全过（三段式结构 / 初始与跨首尾的位移 / 归位那一步的
transition 必须是 none / 连续模式 520 帧每帧恒 -1.2px 且恰好回绕 1 次 / `nearestOffset`
在两种方向 × 5 张 × 前后步共 20 组均为 ±step）。构建通过。

## 待确认

- reverted-* 采用「布局不变、只反向行进」的语义（阅读顺序仍是 0,1,2…，因此 reverted 下
  「下一张」= 索引递减）。若用户想要「镜像布局」（卡片在条内按反向排列，像 RTL 那样），
  需把轨道子元素顺序反转并同步调整锚点 —— 已在回复里说明。

## 二轮：问题依旧的真正原因（提交 `6020715`）

用户回报 `/minecraft/main/index.astro`（`data-type="pausing"` + `data-controller-type="progress"`
+ `data-speed="4"`，两张 `<s-card>` 文案长短差很大）**问题依旧**，并提到进度条亮色填充的圆角不对。

**上一版没修对的地方**：`nearestOffset` 只比距离、**不看方向**。跨首尾时目标卡片同时存在
「前进一整圈的落点」与「倒退一整圈的落点」（画面相同），当「末张卡片占位 < 整圈一半」时
反向那个反而更近 → 内容朝反方向滑 = 滚回开头。判据取决于卡片宽度，所以**等宽卡片的自检
根本照不出来**（上一轮 39 项全用等宽，正好漏掉）。

**改法**：
- 新增 `directedStepOffset(current, target, span, sign)`：先按行进方向过滤，再取最近；
  `jumpTo` 仍用 `nearestOffset`（跳转只要最短动画）
- 锚点从均匀 `step` 换成实测 `cardOffsets[m]`（卡片宽度由内容决定、可不等）
- 进度填充 `transform: scaleX(--p)` → `width: calc(--p * 100%)`：横向缩放会把圆角压扁，
  右端成椭圆帽、与底衬胶囊对不上

**验证**：自检 35 项全过，**新增「卡片宽度不等」维度**，并直接复现旧 bug（同一状态下断言
`nearestOffset` 会选到反向落点、`directedStepOffset` 选对）。教训：轮播的几何自检必须跑
不等宽 + 不等间距，并且要断言「那一步的方向」，而不只是断言落点画面正确。

## 教训（值得长期记住）

1. 「画面相同」的等价位置在**带过渡**时并不等价 —— 归位必须无过渡。
2. 「等价位置」的取舍要区分用途：**步进必须限定方向，跳转才取最近**。
3. 自检的几何参数要有**差异**（宽度、间距），等参数会让一整类 bug 隐身。
4. 组件样式按需注入 → 尺寸测量必须等样式就绪；同理，图片加载后卡片尺寸变化虽然会被
   容器 ResizeObserver 捕获（容器高度会变），但只观察容器仍是已知局限。

## 三轮：data-speed="0" 语法糖（提交 `50ee678`）

需求：speed 为 0 时**永不自动滚动**，且此时不渲染暂停按钮。

- 语义上把「0」与「没写 / 非法」区分：0 = 关闭自动滚动；没写 / 非法 = 取缺省（1 倍 / 2 秒）
- 关闭时连 rAF 都不启动（不排计时器），位移只在手动操作时改变
- `resolveController(isPausing, ctrlType, autoScroll=true)` 加第三参：不自动时 toggle 恒 false；
  continuous 下暂停键是唯一部件 → 整个控制器不渲染（`none`）
- pausing 下：step-pause → 只剩上一张 / 下一张；progress → 进度条保留、去掉暂停键

验证 33 项（含 resolveController 八组合矩阵 + 缺省 / 正常值回归）。
