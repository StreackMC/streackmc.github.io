## 提示框（引用块高级语法）

在引用块开头写入标记，即可渲染为带色提示框：

> [i] 说明性提示（Info）。

> [!] 需要注意的事项（Notice）。

> [x] 警告或风险提示（Warn）。

> [@] 小技巧或建议（Tip）。

> [#7F77DD$自定义] 用 `[#十六进制$标题]` 指定自定义颜色与标题。

在标记前加 `^` 可转义，使其按普通引用渲染。

## 代码

行内代码示例：`npm run build`。

代码块：

```js
// 路径映射示意：src/content/<路径>.md → /<路径>
const slug = entry.id.replace(/(^|\/)index$/, '');
console.log(`生成网址：/${slug}`);
```

```bash
ASTRO_TELEMETRY_DISABLED=1 npx astro build
```
